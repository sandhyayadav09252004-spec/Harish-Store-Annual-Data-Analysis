# Harish Store – Annual Data Analysis

##  Project Description
This project focuses on analyzing the annual sales data of *Harish Store* using *Microsoft Excel*.  
The objective is to understand sales performance, customer behavior, and yearly trends to support better business decision-making.

## Objectives
- Analyze annual sales performance  
- Identify monthly sales trends  
- Find top-selling products  
- Understand customer purchasing patterns  
- Create visual insights using charts and dashboards  

## Tools Used
- Microsoft Excel  
  - Data Cleaning  
  - Sorting & Filtering  
  - Pivot Tables  
  - Charts & Graphs  
  - Dashboard Creation  

##  Dataset Details
The dataset contains:
- Order Date  
- Product Name / Category  
  - Quantity Sold  
- Sales Amount  
- Customer Information  

(Dataset used for academic and learning purposes.)

## Analysis Performed
- Monthly sales trend analysis  
- Product-wise sales performance  
- Revenue contribution analysis  
- Customer segmentation  
- Summary reports using Pivot Tables
  
## Key Insights
- Identified high-performing months  
- Found top revenue-generating products  
- Observed sales patterns throughout the year  
- Visualized insights using charts and dashboards  

## Conclusion
This project demonstrates how *Excel can be used effectively for data analysis* to transform raw data into meaningful business insights.  
It helps in understanding store performance and supports data-driven decisions.
